# 原型开发说明

请自行运行本地服务，并在当前环境提供的浏览器中打开预览。能够直接运行时，不要只向用户提供启动服务器的操作说明。

进行大幅视觉调整前，如果视觉基准不明确或已不再符合当前目标，请使用 Product Design 插件的 `get-context` 技能。当用户提出需要长期保留的原型设计反馈、偏好或决策时，请将它们记录到 `AGENTS.md`。

依据选定的生成式设计稿进行实现时，应将该图片视为布局、组件结构、信息密度、间距、颜色、字体、可见内容和视觉层级的基准。

## 长期产品决策

- v1 制作台的视觉基准是 `docs/design/reference-workbench.png`：一个信息密集的炭灰色三栏生产工作台，包含项目/资源库导航、批量资产审核、修订/Prompt/QA 检查器，以及固定显示的任务栏。
- `docs/design/reference-narrative-atlas.png` 只作为 v1.1“叙事地图”的布局、组件结构和信息密度基准；颜色、边框、控件和交互状态必须继承 `reference-workbench.png` 的炭灰色设计系统。除非未来建立产品级主题切换，不得为叙事地图单独引入浅色模式，也不要将该场景地图布局并入 v1 生产制作台。
- 界面图标使用 Phosphor Icons。不要引入手工绘制的 SVG 图标、装饰性渐变或表情符号。
- 生成任务统一由顶栏“生成中心”管理：会话列表中的“新建会话”才创建空会话，叙事地图“生成缺失资产”可以创建带场景上下文的会话；生成中心是独立的完整工作区（`/generation`、`/generation/:sessionId`），桌面为 232px 会话列表、对话、默认 400px 可调工作面板；1200px 以下收起工作面板，900px 以下会话抽屉和对话/工作面板切换。后台规划由持久队列和独立 worker 承担，页面卸载不停止任务。参考预览与选择必须分开，规划恢复不重复用户消息、不自动确认付费生成；同一会话允许多个不可变生成批次。
- 右侧检查器按资产语义切换：媒体使用版本/QA 视图，叙事与设计文档使用案卷式阅读视图，角色与物品使用关联媒体画廊；长内容编辑使用宽抽屉并保存为不可变候选。
- 用户可见的资产类型与领域统一显示中文，英文 subtype、kind 和稳定 Key 只作为内部标识或 tooltip 信息。
- 资产库侧栏使用任务视图 predicate，而不是 `asset.category` 做唯一筛选依据；“媒体”只能作为分组标题，角色立绘、场景背景、剧情 CG、物品图标、结局插画和音频是互斥叶子入口。未识别 subtype 必须落入对应分组的“其他类型”，并仍可从“全部资产”访问。
- 默认资产视图是“场景”。场景来自现有 `scene`、`event`、`story_event`、`dialogue_scene` 资产的派生集合；章节归属、`ready/required` 覆盖率和缺失数通过叙事地图关联，不创建第二套 Asset ID。场景检查器必须提供“在叙事地图中打开”，叙事地图标题、Key 和关系节点可以反向定位资产库。
- “项目规范”分组必须显示并可编辑风格圣经与 Prompt 配方。风格圣经使用安全 Markdown 源码 + 实时预览，Prompt 配方使用字段表单 + 原始 JSON；保存只创建不可变候选，批准后才写回源文件。`production/style-bible.json` 是批准时生成的机器 profile，不单独作为资产行。
- 项目规范的外部来源哈希、缺失和漂移必须在检查器可见；缺失保留最后批准版本，漂移不得静默批准。新增文档和抽屉继续继承制作台炭灰色主题。
- 紧凑筛选和单选表单优先使用统一的 `SelectMenu`（Phosphor 下拉指示、listbox ARIA、键盘与外点关闭），避免依赖操作系统原生菜单；多选关系编辑仍可使用专用控件。

- 生成中心规划与文字产物统一使用供应商文字路由，不允许静默读取个人 Codex 默认模型或登录；规划运行目录隔离，缺少供应商凭据时明确提示解锁。连接灯不能代替执行进度，commentary 不得隐藏后续流式方案。
- 生成中心隐藏全局近期任务底栏，进度在结果面板查看。确认预览必须就地提供警告勾选、禁用原因及请求错误；普通编辑不能被无关项目目录变化阻断，最终快照刷新后须重新核对再确认。
